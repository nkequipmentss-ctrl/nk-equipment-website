# NK Equipments Solution

A premium corporate website for a Pakistan-based international importer and supplier of used heavy machinery. The experience presents equipment categories, sample inventory, global sourcing capabilities, services, customer trust content, and multiple lead-capture paths in a modern industrial design.

## Technology

- TanStack Start and React 19
- TypeScript
- Tailwind CSS tooling with a custom responsive CSS design system
- Lucide React icons
- Netlify Forms for contact, quote, machine request, and newsletter submissions
- Netlify TanStack Start deployment adapter

## Main Features

- Cinematic full-screen hero and premium dark industrial visual system
- Responsive equipment category, inventory, brand, gallery, testimonial, FAQ, and blog sections
- Live inventory search with an equipment-sourcing fallback state
- Worldwide sourcing map with highlighted import markets
- Contact, quote request, machine request, and newsletter forms
- Mobile navigation, loading sequence, scroll reveals, modals, and WhatsApp action
- Search metadata, semantic headings, reduced-motion support, and lazy-loaded imagery

## Local Setup

```bash
pnpm install
pnpm dev
```

The local development server uses the port configured by the TanStack Start template. For full Netlify feature emulation, run the project through Netlify Dev.

## Before Launch

Replace the sample phone number, email address, office location, WhatsApp destination, social links, inventory records, customer names, and testimonials with verified company information. Review form notifications in Netlify project settings so new leads reach the appropriate team.
